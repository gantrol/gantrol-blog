# 计算之心首页视觉方案 V2

状态：GPT Image 2 视觉方案，尚未进入网站实现。

## 方案结论

首页从“泛 AI 科技落地页”收敛为一张简洁的个人名片与内容索引：以 **计算机心理学** 为唯一定位，以新版指南针头像为唯一主图，以历史热门文章和当前作品为主要内容。

参考项目只抽取各自稳定的设计规则：

- `ai-beauty-dictionary`：暖中性色、单一强调色、1px 边界、静态组件无阴影、4px 间距系统。
- `llm-timeline`：共享容器中的分隔列表、清楚的编号和元信息、克制的导航与编辑式信息层级。
- 不复制两套产品的具体页面布局、产品色或品牌图形。

## 本轮修订

1. 头像改用用户提供的 `gantrol.svg`，不让生成模型重新设计。PNG 仅用于视觉稿和位图回退。
2. 删除蓝紫渐变、科技背景、玻璃拟态、悬浮光效、衬线展示字体和大面积装饰。
3. Hero 主标题固定为“计算机心理学”；AI、软件与心理作为三条内容主线，不再做成 emoji 身份卡。
4. “最近更新”改为“历史热门”，不显示日期或新鲜度标签。
5. 主作品更新为 AIY、模型纪年、Agent Controller；旧工具降到后续“更多工具”。

## 页面结构

### 1. 顶部导航

- 高度：桌面 64px，移动端 60px。
- 左侧：32px 新头像 + `Gantrol`。
- 桌面右侧：`文章`、`作品`、`关于`、搜索、主题切换。
- 移动端右侧：搜索和菜单；不压缩显示桌面链接。
- 当前项只用字重或 2px 珊瑚色下划线，不使用胶囊背景。

### 2. Hero

- 元信息：`黄健楸 · GANTROL`
- H1：`计算机心理学`
- 描述：`写 AI 与软件，也用计算机理解人。`
- 主动作：`阅读文章`
- 次动作：`GitHub ↗`
- 新头像在桌面约 144px、移动端 96–112px；它是首屏唯一的大图形。
- 桌面首屏约 300px 高，不做全屏 Hero。

### 3. 内容方向

一个白色描边容器，内部三行，以细分隔线组织。它位于 Hero 与历史热门之间，用来说明站点内容边界，而不是制造新的卡片墙。

| 编号 | 标题 | 说明 | 状态或路径 |
| --- | --- | --- | --- |
| 01 | 软件工程 | 从理论到实践，从基础知识到创新思维，探索软件开发的无限可能 | `/software/` |
| 02 | AI探索 | Prompt 辞典、AI·第一名、Deep Research，以及大模型理论与实践 | `/AI/TOP1` |
| 03 | 心理爱好 | 认知心理学，高效学习方法，决策理论，让思维更清晰 | `施工中`，暂不提供链接 |

其中“软件工程”和“AI探索”显示行尾箭头；“心理爱好”以文字状态“施工中”替代箭头。正文使用普通字重，不使用整段加粗。

### 4. 历史热门

一个白色描边容器，内部三行，以细分隔线组织；不拆成三张卡。

| 编号 | 类型 | 标题 | 路径 |

## 设计令牌

### 颜色

| 语义 | 浅色模式 | 用途 |
| --- | --- | --- |
| Background | `#F8F7F3` | 页面底色 |
| Surface | `#FFFEFB` | 列表与作品卡 |
| Sunken | `#F1EFEA` | 极少量次级状态 |
| Ink | `#262320` | 标题与主文字 |
| Secondary | `#4A453E` | 正文与次要文字 |
| Muted | `#6C665E` | 元信息 |
| Border | `#DEDAD2` | 默认边界 |
| Border strong | `#C8C2B8` | Hover 边界 |
| Brand coral | `#FB7370` | 主按钮、编号、链接与焦点 |

珊瑚色是全站唯一强调色；除头像内部原有渐变外，界面不使用渐变。

深色模式沿用同一语义，不恢复霓虹效果：背景、表面、文字和边界做中性反转，珊瑚色仍为唯一强调色。

### 字体与尺寸

- 字体：`Inter, "Segoe UI Variable", "Microsoft YaHei UI", "PingFang SC", system-ui, sans-serif`。
- 中文不加字距；字重只使用 400、500、600。
- 桌面 H1：约 64px；移动端 H1：约 44px。
- Section H2：28px；正文：16px / 28px；元信息：12–13px。

### 布局与组件

- 内容最大宽度：1120px。
- 基础间距：4px；常用值：8 / 12 / 16 / 24 / 32 / 48 / 72px。
- Section 间距：桌面 72–96px；移动端 48–64px。
- 卡片圆角：14px；边界：1px；静态阴影：无。
- Hover：只改变边界或浅背景，位移不超过 1px。
- 动效：120 / 180 / 220ms；尊重 `prefers-reduced-motion`。
- 焦点：2px 珊瑚色描边 + 2px offset；点击目标不小于 44px。

## 响应式规则

- `>= 960px`：Hero 左文右头像；内容方向保持三行共享容器；作品三列；历史文章保持横向信息行。
- `640–959px`：Hero 比例收紧；作品可两列加一张通栏。
- `< 640px`：导航折叠；Hero 保留头像但减小；内容方向和热门文章行允许说明或标题换行；作品单列。
- 移动端左右留白 20px，不缩小字号来硬塞内容。

## 头像接入规则

- 视觉源文件：`docs/design/assets/gantrol-avatar-v2.svg`。
- 位图回退：`docs/design/assets/gantrol-avatar-v2.png`。
- 实现时应直接以 SVG 替换站点导航和 Hero 的品牌图形，避免从视觉稿中裁切头像。
- 保留原始灰环、白色内圈、珊瑚指南针与中心圆点，不加阴影、外发光或新底板。
