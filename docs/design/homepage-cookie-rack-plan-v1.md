# 首页轨道方案 V1：饼干冷却架

> 本文件只是一份视觉与交互提案，不接入生产首页、不修改现有组件。

## 视觉探索稿

- [GPT Image 2 桌面探索稿](./homepage-cookie-rack-desktop-v1-gpt-image-2.png)

探索稿用于确认气质与构图；正式实现中的文字、真实 Logo、轨道和饼干轮廓都应由 HTML、SVG 与 CSS 渲染，不把整张位图放进页面。

## 一句话方案

把六个作品变成刚出炉的“项目饼干”，安放在一圈有轻微承重感的冷却架轨道上；中央 Gantrol 头像退为很小的烙印，只负责指示当前焦点。

## 借鉴点

借鉴 `D:\project\test-void0\llm-timeline` 的是模型烤盘与饼干构思，不是流星：

- 12–13 个波瓣组成略有差异的手作饼干轮廓。
- 奶油色饼干面、金棕色侧边、细薄烤色和落地阴影形成层次。
- 真实 Logo 像糖霜印记一样居中，但保持各项目原色。
- 饼干有小幅倾角和轻微叠放，不排列得像机械圆点。
- 轨道在节点下方产生很轻的下沉，暗示饼干的视觉重量。
- 悬停时饼干抬起、回正，阴影变深，像从烤盘上拿起。

不照搬参考站的横向时间线，也不使用它的具体曲线路径；这里只迁移“饼干 + 烤盘 + 重量反馈”的设计语法。

## 桌面构图

- 左侧标题、说明和按钮保持现有布局，不改首页信息架构。
- 右侧使用约 `680 × 460px` 的视觉区域，保留椭圆关系，但轨道改成哑光暖米色冷却架。
- 轨道由一条主线和一条很淡的伴随线构成，避免金属首饰圈、科幻 HUD 或发光星轨的感觉。
- 六枚作品饼干沿轨道分布；允许一组相邻节点重叠 `6–10px`，其余保持呼吸感。
- 中央只保留安静的小型圆形烙印，不再成为主视觉。

### 建议尺寸

| 元素 | 桌面 | 手机 |
| --- | ---: | ---: |
| 饼干外径 | `76px`，激活 `82px` | `56px`，激活 `60px` |
| Logo 可视区 | `34–38px` | `26–28px` |
| 中央烙印外径 | `64px` | `44px` |
| 中央头像可视区 | `28–32px` | `20–22px` |
| 标签 | `13px / 1.35` | `12px / 1.3` |
| 轨道主线 | `1.25px` | `1px` |

这会把目前约 `190px` 的中心主体降到 `64px` 外框，头像本身只保留约 `30px`，视觉层级明显让位给作品。

## 饼干造型规则

每枚饼干使用项目 ID 作为随机种子生成轮廓，保证刷新后不抖动：

- 波瓣数在 `12–13` 之间。
- 半径抖动控制在 `±3%`，单瓣宽度抖动控制在 `±4%`。
- 节点初始旋转限制在 `-3deg` 到 `3deg`。
- 正面使用柔和径向渐变；侧边向下偏移 `2–3px`，形成烤制厚度。
- 不添加巧克力豆、碎屑、咬痕、表情或写实食物纹理。

## 轨道规则

- 颜色以暖灰米色为主，哑光、细、低对比，不使用红色尾迹或高光金属质感。
- 每枚饼干下方允许 `3–5px` 的局部下沉；下沉曲线必须连续，不能像折线挂点。
- 只在少数关键位置放置小圆支点，支点不带装饰性立柱。
- 默认建议静止。若保留现有自动环行，速度不快于 `140s/圈`，且饼干面逆向补偿、始终保持文字和 Logo 直立。

## 交互

1. `hover` / 键盘聚焦：饼干上移 `5px`、旋转回 `0deg`、缩放到 `1.04`，阴影加深。
2. 当前节点：增加 `1px` 珊瑚色细描边；珊瑚色只表示状态，不给轨道整圈染色。
3. 中央烙印：切换为当前作品的小型预览或方向指示，不放大。
4. 轨道反馈：当前饼干下面的下沉减少 `2px`，表现“被拿起”后的回弹。
5. `prefers-reduced-motion`：取消位移、旋转与回弹，仅保留描边和阴影变化。

手机端不强行压缩完整椭圆，建议改成一段横向冷却架：屏幕内显示 2.5–3 枚饼干，可轻扫浏览；中央头像移到轨道起点，保持小尺寸。

## 设计令牌建议

```css
--cookie-face: #fff8eb;
--cookie-face-mid: #f7ead2;
--cookie-bevel: #e7bd75;
--cookie-side: #bd7d30;
--cookie-shadow: rgb(85 55 24 / 18%);

--rack-main: #c8b58f;
--rack-soft: #dfd2b9;
--rack-node: #b9904f;
--cookie-active: #fb7370;
```

深色模式不应简单反相：饼干面可改为 `#342b22`，侧边为 `#8e5f2d`，轨道为 `#756751`，Logo 仍保留原色与足够对比度。

## 明确排除

- 流星、彗星、星点、速度尾迹和太空背景。
- 霓虹光圈、仪表盘刻度和科幻界面。
- 巨大的中央头像。
- 光亮黄铜、首饰圈、装饰立柱。
- 写实曲奇、卡通食品和过度可爱化。
