> 只做方案，不接入生产首页、不修改现有组件。V1 轨道方案保留作对照，本版完全取消轨道。

探索稿只用于确认构图和气质。正式实现必须使用真实 Logo、HTML、SVG 与 CSS，不把整张生成图作为页面图片。

## 一句话方案

右侧不再围绕头像旋转，而是一只正在陈列作品的“项目烤盘”：六枚项目饼干直接放在烘焙纸上，Gantrol 头像缩成右下角的制作者烙印。

## 相比轨道版的变化

- 删除椭圆、路径节点、环行动画和中心构图。
- 六个项目从“卫星”变为同一批出炉的“作品饼干”。
- 头像不再占据中心，只留下 `24–28px` 的指南针烙印。
- 构图从环形阅读改为稳定的两行阅读，项目名称更容易扫视。
- “模型烤盘”的隐喻直接可见，不再需要依靠运动解释。

## 桌面构图

- 左侧现有标题、说明和按钮完全不动。
- 右侧放置约 `620 × 390px` 的横向浅烤盘，接近俯视，仅保留 `2–3deg` 的轻微透视。
- 烤盘采用圆角双层卷边，内部铺暖象牙色烘焙纸。
- 六枚饼干以 `3 × 2` 为基础，但不能机械对齐：横向错位 `8–16px`、纵向错位 `4–10px`，各自旋转 `-3deg` 到 `3deg`。
- 标签紧邻饼干下方，仍是页面文字而不是烤在饼干上的文字。
- “六个主要产品与作品”保留在盘外下方，作为区域说明。

### 建议尺寸

| 元素 | 桌面 | 手机 |
| --- | ---: | ---: |
| 烤盘 | `620 × 390px` | `310 × 470px` |
| 烤盘可见外沿 | `10–12px` | `8px` |
| 饼干外径 | `78px`，激活 `84px` | `58px`，激活 `62px` |
| Logo 可视区 | `34–38px` | `26–30px` |
| 头像烙印外径 | `38px` | `32px` |
| 头像可视区 | `24–28px` | `20–22px` |
| 项目标签 | `13px / 1.35` | `12px / 1.3` |

手机端把烤盘转为竖向 `2 × 3` 布局，不需要横向滑动，也不缩成难以点击的小饼干。

## 材质控制

烤盘必须“看得出是什么”，但不能像商品摄影：

- 外沿使用低对比暖香槟色，取消镜面高光。
- 只用两到三层 CSS 渐变表达卷边，厚度控制在 `10–12px`。
- 烘焙纸只保留极淡的纤维噪点，不出现油渍、焦痕或褶皱照片纹理。
- 整体阴影要宽、浅、贴近页面，避免烤盘像悬浮的金属设备。
- 饼干可以比盘体更立体，形成明确的视觉主次。

## 饼干规则

- 每个项目 ID 固定生成 12–13 波瓣轮廓，刷新时不变化。
- 奶油色正面、金棕色侧边、`2–3px` 厚度和柔和落影延续参考项目的饼干语言。
- Logo 保留真实原色，不统一染成珊瑚色。
- 可允许一组饼干轻微靠近或重叠 `4–6px`，但名称不能被挡。
- 不增加巧克力豆、碎屑、咬痕、表情或写实食物纹理。

## 交互

1. 悬停或键盘聚焦时，饼干上移 `6px`、回正到 `0deg`、缩放至 `1.045`。
2. 当前饼干增加 `1px` 珊瑚色内描边，烘焙纸上出现极淡的对应圆形压痕。
3. 点击后沿用现有项目跳转；烤盘本身不响应点击。
4. 烙印只作为品牌签名，可在当前项目变化时轻微转向，但不放大。
5. `prefers-reduced-motion` 下取消位移和转向，只保留描边与阴影。

不建议再做整盘旋转或自动轮播。烤盘是稳定的展示面，运动只发生在用户正在选择的那枚饼干上。

## 设计令牌建议

```css
--tray-rim-light: #ead9bb;
--tray-rim-mid: #c9ac78;
--tray-rim-dark: #a78552;
--tray-paper: #fff9ef;
--tray-paper-grain: rgb(125 95 54 / 4%);
--tray-shadow: rgb(62 43 24 / 14%);

--cookie-face: #fff8eb;
--cookie-face-mid: #f7ead2;
--cookie-bevel: #e7bd75;
--cookie-side: #bd7d30;
--cookie-active: #fb7370;
```

深色模式下烤盘外沿改为暗铜灰，烘焙纸改为暖深褐；不要直接反相，也不要让盘体比 Logo 更亮。

## 明确排除

- 任何轨道、椭圆路线、环行节点和自动公转。
- 流星、彗星、星点、尾迹、霓虹和科幻 HUD。
- 居中的大头像。
- 写实烤箱、炉灶、厨师工具和食品摄影。
- 过厚、过亮、像首饰或高档餐具的金属边框。
