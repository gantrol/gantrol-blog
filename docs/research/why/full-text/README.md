# 开放全文离线保存

这个目录只保存可以合法本地留存的开放获取版本。

## 保存规则

1. 优先保存出版社明确标注为开放获取的版本、作者存档或机构库版本。
2. 不绕过付费墙、登录、验证码或访问控制。
3. 每个文件必须能对应 `references.bib` 中的 citekey。
4. 文件名格式：`citekey--short-title.pdf`。
5. 在下表记录原始来源、版本和许可；许可未知时只保存链接，不保存全文。
