# 逆向评估：从论据倒推“最多能证明什么”

正向评估容易从理论名称出发，把任何相容结果都收进理论。这里反过来：暂时隐藏理论标签，只看研究真正操纵、比较和测量了什么，再决定它最多能托住哪一层命题。

```text
原始比较与结果
  → 被识别的局部效应
  → 仍然相容的竞争机制
  → 最窄可守命题
  → 能否上推为一般观点
```

## 二、倒推后的上层观点

把这些论据重新组合，得到的不是“哪一派理论获胜”，而是以下可信度排序。

### 高可信的窄命题

- 行动受到能力、机会和环境结构约束，不能由“想不想”单独解释。
- 意向、期望、价值、目标和计划能提高行动概率，但没有一个是充分条件。
- 结果与预期的差异参与学习；稳定线索和重复可使行为部分自动化。
- 归属威胁、相对地位、显著身份、真实规范和未来互动会改变社会行动。
- 情绪、好奇、无聊和奖励结构改变注意、价值更新和行动准备，但不直接指定唯一动作。
- 同一帮助、合作、学习或消费行为经常由多种动机共同产生。

### 只能缩窄保留的观点

- “提高信心会提高表现”须改为效能与表现的双向反馈，并优先寻找掌握经验。
- “奖励挤出内在动机”须限定到初始兴趣、预期性、有形性、控制体验、撤奖后指标和时间窗。
- “社会规范消息有效”须区分真实共同知识/制裁与抽象的描述性文案。
- “意义使人坚持”对具体任务有因果支持，对人生长期结局主要仍是关联。
- “心流提高绩效”目前更稳妥的写法是二者共同出现，因果方向未决。

### 应拒绝的强版本

- 一个内部变量可以解释某次行动的全部原因。
- 有意向就会行动；高自信就会成功；目标越难越好。
- 奖励总有益或总有害；wanting 就是 liking；多巴胺就是快乐或欲望。
- 排斥必然使人亲社会；身份必然导致敌意；人只关心地位或相对收益。
- 人天生直觉合作；惩罚总促进合作；公开帮助必虚伪、私下帮助必纯粹。
- 复杂系统的每次结果都存在可恢复的唯一心理原因。

## 三、对具体“为什么”的倒推模板

分析“某人为什么做 X 而不做 Y”时，按以下顺序落笔：

1. **结果层**：具体发生了什么，X 的备选项 Y 是什么？
2. **近端条件**：当时有哪些能力、机会、时间、线索、反馈和社会对象？
3. **区分性资料**：改变哪一个条件后，X 相对 Y 的概率发生变化？
4. **候选机制**：价值、预期、归属、身份、习惯、情绪等哪些机制与变化相容？
5. **竞争解释**：哪些机制做出同样预测，现有资料无法区分？
6. **最窄结论**：只写到论据能托住的层次，不把群体平均效应冒充个人事实。

推荐结论句式：

> 在条件 C 下，因素 F 相对于比较条件提高了行为 X 的概率；结果与机制 M 相容，但也与 M2、M3 相容。现有资料不能识别唯一动机，也不能保证换一个人、情境或时间尺度仍成立。

## 四、复杂系统中的停止规则

遇到以下任一情况，不继续强问“真正为什么”，而改写问题或停止在统计解释：

- 多条充分路径能产生同一结果，且没有区分性操纵或自然变化；
- 关键初始条件没有记录，系统对微小差异或历史路径高度敏感；
- 只能估计总体概率，不能稳定反事实预测这个人的这一次行为；
- 构念由同一自报或同一行为循环定义，无法独立测量；
- 理论对任何结果都能事后兼容，没有失败预测；
- 继续细分不会改变预测、干预或理解，只增加故事性细节。

此时允许的最终标签是：`多重解释不可识别`、`仅群体统计关联`、`个体原因未知`、`路径依赖，无法点识别`、`当前问题无可检验含义`。
