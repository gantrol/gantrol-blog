# 核心行动动力：证据包

最后检索：2026-08-23

本文件回答：人为什么形成意向、开始行动、坚持、拖延或在没有重新思考时重复行为？

## 总结

```text
能力/机会
  → 成功期望与自我效能
  → 价值、成本与延迟
  → 意向与目标
  → 执行计划
  → 情境线索与习惯
  → 行为结果
  → 更新效能、价值和下一次选择
```

这些理论多半解释不同环节，不能因为都与行为相关就视为彼此互斥。

| 模块 | 当前最稳妥结论 | 关键边界 |
| --- | --- | --- |
| COM-B | 行动至少还受能力与机会约束 | 主要是诊断框架，不是已完整验证的三变量因果模型 |
| TPB | 态度、规范和感知控制预测意向；意向预测部分行为 | 意向变化显著大于行为变化；真实机会与习惯仍重要 |
| 期望—价值 | 成功期望、价值和成本共同影响选择与坚持 | 简单乘法不总优于各成分；过去表现反过来塑造两者 |
| 自我效能 | 任务特定的“我能做到”与尝试、坚持、表现相关 | 人内数据中，过去表现到后续效能通常强于反方向 |
| 目标设定 | 具体困难目标常优于“尽力而为” | 复杂任务效应较弱，也可能窄化注意或诱发作弊 |
| 执行意图 | if-then 计划帮助把已有意向转成行为 | 不创造目标价值、技能、机会或承诺 |
| 习惯 | 稳定情境中的重复可形成线索—反应关系 | 过去频率不等于习惯；自动性的自报测量有局限 |
| 时间折扣与拖延 | 延迟会折损价值；厌恶、冲动、低效能会增加拖延 | 折扣受结果和测量情境影响，不是固定人格常数 |

## 1. COM-B

1. `michie2011behaviour` — **框架/限定**。比较 19 个行为改变框架，提出能力、机会、动力共同构成行为诊断系统。支持其作为完整性清单；未用实验验证三者的必要性、充分性或交互形式。DOI：[10.1186/1748-5908-6-42](https://doi.org/10.1186/1748-5908-6-42)。
2. `willmott2021comb` — **相关支持/限定**。青年饮食与身体活动的横断面模型中，COM 变量解释约 23%–31% 的行为差异；自报、同一时点，不能证明因果必要条件。DOI：[10.1186/s12889-021-11019-w](https://doi.org/10.1186/s12889-021-11019-w)。
3. `keyworth2020combmeasure` — **测量支持/限定**。开发 6 题 COM-B 量表，在医护人员样本中得到可接受的结构与重测结果；单题子域、自评与天花板效应限制其替代客观能力和机会。DOI：[10.1111/bjhp.12417](https://doi.org/10.1111/bjhp.12417)。

**栏目用法**：先问“不想、不会、不能、没机会，还是已经自动化？”，再进入深层动机理论。

## 2. 计划行为与意向—行为鸿沟

4. `ajzen1991planned` — **理论原型**。态度、主观规范和感知控制形成意向；意向和接近真实控制的感知控制预测行为。主要针对审慎、目标导向行为。
5. `armitage2001tpbmeta` — **支持/限定**。185 项独立研究中，TPB 解释约 39% 的意向差异和 27% 的行为差异；客观行为低于自报，主观规范通常最弱，多数研究仍为相关设计。
6. `mceachan2011tpbhealth` — **支持/异质性**。206 篇论文、237 个前瞻检验；不同健康行为的解释率明显不同，短期与自报行为预测更好。DOI：[10.1080/17437199.2010.521684](https://doi.org/10.1080/17437199.2010.521684)。
7. `hagger2024tpblongitudinal` — **限定强版本**。预注册纵向元分析在控制构念稳定性和过去行为后，跨时路径普遍较小，也很少得到理论预期的交叉滞后因果。DOI：[10.1080/10463283.2023.2225897](https://doi.org/10.1080/10463283.2023.2225897)。
8. `webb2006intention` — **因果支持/鸿沟**。47 个随机或准随机实验中，意向改变约 `d=.66`，行为改变约 `d=.36`；意向有作用但远非充分条件。
9. `sheeran2016gap` — **综合限定**。把未行动拆为无意向、倾向但未启动、执行失败等不同类型；计划、机会、记忆、自我调节和习惯均可能构成障碍。DOI：[10.1111/spc3.12265](https://doi.org/10.1111/spc3.12265)。

**栏目用法**：分别记录想不想、是否形成计划、是否遇到机会、是否启动、是否坚持，不能只记录“动机强度”。

## 3. 期望—价值

10. `eccles2020sev` — **理论综述**。成功期望、内在价值、成就价值、效用价值和成本共同作用，并受发展、文化、身份和具体情境影响。DOI：[10.1016/j.cedpsych.2020.101859](https://doi.org/10.1016/j.cedpsych.2020.101859)。
11. `vaneerde1996vroom` — **支持成分/冲突简单乘法**。77 项工作动机研究中，期望、工具性和效价与偏好、意向、努力和表现总体正相关；完整乘法没有稳定优于单独成分。DOI：[10.1037/0021-9010.81.5.575](https://doi.org/10.1037/0021-9010.81.5.575)。
12. `nagengast2011expectancyvalue` — **大样本兼容/非因果**。57 国、398,750 名学生中，科学自我概念、价值及交互预测参与和职业意向；横断面设计和极大样本限制因果与效应大小解释。DOI：[10.1177/0956797611415540](https://doi.org/10.1177/0956797611415540)。
13. `hulleman2009utility` — **现场因果支持/异质性**。高中课堂随机实验中，把课程联系个人生活主要帮助原本成功期望较低的学生。DOI：[10.1126/science.1177067](https://doi.org/10.1126/science.1177067)。
14. `hulleman2010utility` — **机制支持**。自我生成用途联系提高感知效用，并改善部分低表现学生的兴趣、成绩和专业意向；自己生成与被告知“有用”不能假定等效。DOI：[10.1037/a0019506](https://doi.org/10.1037/a0019506)。

## 4. 自我效能

15. `bandura1977selfefficacy` — **理论原型**。任务特定能力判断影响是否开始、努力和遇挫后的坚持。DOI：[10.1037/0033-295X.84.2.191](https://doi.org/10.1037/0033-295X.84.2.191)。
16. `bandura1977mediating` — **实验支持/特定边界**。恐惧症干预中，掌握经验产生更强且更可泛化的效能判断，效能预测后续接近行为；治疗也同时改变能力、恐惧和结果预期。DOI：[10.1037/0022-3514.35.3.125](https://doi.org/10.1037/0022-3514.35.3.125)。
17. `stajkovic1998selfefficacy` — **相关支持/复杂度边界**。114 项研究、N=21,616，自我效能与工作表现平均相关约 `.38`；复杂任务关系较弱，共同原因和反向因果仍可能存在。DOI：[10.1037/0033-2909.124.2.240](https://doi.org/10.1037/0033-2909.124.2.240)。
18. `sitzmann2013selfefficacy` — **关键反向因果证据**。同一个人随时间的数据中，控制共同趋势后，效能到未来表现约 `.06` 且不显著；过去表现到效能仍约 `.30`。提升真实掌握经验可能比单纯鼓励更有效。

## 5. 目标设定

19. `locke2002goal` — **条件性支持**。具体困难目标通过注意、努力、坚持和策略影响表现，但需要承诺、反馈、能力和资源。
20. `mento1987goalmeta` — **元分析支持**。综合 1966–1984 年研究，困难目标优于容易目标，具体困难目标优于模糊“尽力而为”；语料较旧且多为短期、易量化任务。DOI：[10.1016/0749-5978(87)90045-8](https://doi.org/10.1016/0749-5978(87)90045-8)。
21. `wood1987complexity` — **任务复杂度边界**。125 项研究中，目标设定在简单任务上的效应约 `d=.76`，复杂任务约 `d=.42`；新颖任务可能应优先学习目标。DOI：[10.1037/0021-9010.72.3.416](https://doi.org/10.1037/0021-9010.72.3.416)。
22. `schweitzer2004unethical` — **负面因果证据**。具体目标未达成者更可能虚报结果，接近目标时尤其明显；目标增强的是达到指标的动力，不保证产生真正需要的行为。DOI：[10.2307/20159591](https://doi.org/10.2307/20159591)。

## 6. 执行意图

23. `gollwitzer2006implementation` — **早期强支持**。94 个独立检验、N=8,461，if-then 计划对目标达成总体 `d=.65`；研究场景和结果测量混合，且它只帮助执行已有目标。
24. `wang2021mcii` — **现实效应限定**。21 项现场研究、N=15,907，心理对照加执行意图总体 `g=.336`；互动指导强于只发材料，并检测到发表偏差。DOI：[10.3389/fpsyg.2021.565202](https://doi.org/10.3389/fpsyg.2021.565202)。
25. `webb2006intention` — **对照基准**。强化“想做”产生的行为收益明显小于意向收益，因此执行问题要单独测量。

## 7. 习惯与自动行动

26. `ouellette1998habit` — **早期综合支持/测量边界**。稳定情境中的高频行为更受过去行为预测；过去频率也可能混入稳定偏好和机会，不能直接等同习惯。
27. `wood2002everydayhabits` — **自然情境支持**。逐小时经验日记显示，高频稳定行为发生时，人较少思考当前行动；这是自动性的旁证，不是随机形成习惯的证据。DOI：[10.1037/0022-3514.83.6.1281](https://doi.org/10.1037/0022-3514.83.6.1281)。
28. `lally2010habits` — **纵向形成证据**。96 人重复简单健康行为 12 周，自动性呈渐近增长；达到平台的估计约 18–254 天，广为流传的“21 天”不受支持，约 66 天也不是普遍期限。
29. `wood2016habit` — **理论整合**。习惯常在追求目标时形成，随后可由情境线索直接触发；目标与习惯不是简单二选一。
30. `hagger2023habitmeta` — **大规模元分析支持/测量警告**。267 项研究中，习惯和意向各自预测行为；含频率项目的自报习惯量表得到更强关系，提示共同方法和定义循环。DOI：[10.1037/mot0000294](https://doi.org/10.1037/mot0000294)。
31. `danner2008habit` — **情境稳定限定**。只有高频且情境稳定时，强习惯才削弱意向—行为关系；主要为观察设计。DOI：[10.1348/014466607X230876](https://doi.org/10.1348/014466607X230876)。
32. `stojanovic2022context` — **较强情境证据**。6 周纵向操纵及应用数据表明，稳定时间和地点提高自动性与单次目标达成；学生、自选行为与自报仍限制泛化。DOI：[10.3389/fpsyg.2022.883795](https://doi.org/10.3389/fpsyg.2022.883795)。

## 8. 时间折扣与拖延

33. `frederick2002discounting` — **关键综述/反固定折扣率**。观察到的时间偏好混入不确定性、流动性、情绪预期、金额、框架和信任，不能把眼前选择直接写成固定短视人格。DOI：[10.1257/002205102320161311](https://doi.org/10.1257/002205102320161311)。
34. `steel2006temporal` — **理论整合**。以期望、价值、延迟和冲动敏感性统一多种动力理论；公式是解释性近似，不可冒充个人行动的精确计算器。
35. `steel2007procrastination` — **元分析支持/因果限定**。216 项作品、691 个独立相关中，任务厌恶、延迟、低效能、冲动、低自制和易分心是较强预测因素；研究主体仍为相关设计。
36. `gelino2024discounting` — **测量支持/因果限定**。系统综述显示折扣任务具有可用的重测可靠性；可靠不等于固定人格特质，也不证明折扣导致某个现实行为。DOI：[10.1002/jeab.910](https://doi.org/10.1002/jeab.910)。

## 对具体个人停止归因的门槛

满足任一项时，不写“真正原因就是”：

- 同一行为存在多条足以产生结果的路径；
- 当前数据不能区分两个理论；
- 没有明确、可辩护的反事实；
- 只有事后自述，缺少行为或时间顺序；
- 只有群体平均效应，却要解释某个人的一次行为；
- 事件高度依赖初始条件和偶然路径。

此时使用：

> 已知这些因素会提高或降低该行为的概率，但当前证据不能识别唯一、充分的原因。
