# 论点与论据评估规则

## 1. 五层结构

每个主题按以下层级记录：

```text
观念（construct / concept）
  → 观点（较宽的理论判断）
    → 分论点（有条件、可被证伪的命题）
      → 论据（具体研究结果，不只是论文名称）
        → 论据强度与边界
```

例子：

```text
观念：自我效能
观点：相信自己能完成任务，会影响是否行动
分论点：提高任务特定自我效能，会提高下一次任务表现
论据：个体内元分析中，控制共同趋势后，效能→表现很弱；表现→效能更强
评估：相关关系强，单向因果论据弱；强版本需要改写
```

“观念存在”“能被量表测量”“与行为相关”“改变它会改变行为”“它是某个人这次行为的原因”是五个不同命题，不得互相替代。

## 2. 论据强度的四个维度

每项论据分别评价，不用单一证据金字塔。

### 因果识别

- `A`：随机操纵、可信自然实验，或在明确假设下可识别的因果设计；
- `B`：纵向、个体内、准实验或机制证据，仍有重要替代解释；
- `C`：横断相关、单次自报、无法确定方向；
- `—`：研究本来只回答描述、测量或概念问题。

### 直接性

- `A`：直接记录目标行为或实际结果；
- `B`：可靠代理、临近行为或多方法测量；
- `C`：意向、态度、自报概念或远端代理；
- `—`：与该分论点不在同一层次。

### 重复与一致性

- `A`：多项独立重复、预注册多实验室研究，或高质量元分析总体一致；
- `B`：多项研究支持但存在异质性、方法依赖或发表偏差；
- `C`：单项、小样本、同一团队或尚无独立重复；
- `X`：有足够精度的研究得到明显冲突结果。

### 泛化

- `A`：跨任务、人群、文化和现实场景仍大体成立；
- `B`：多个场景支持，但有明确调节和异质性；
- `C`：只在特定实验范式、样本或短时间尺度得到支持；
- `—`：理论上不应外推或尚无资料。

## 3. 综合强度

综合强度只针对一条写清条件的分论点：

| 标签 | 含义 |
| --- | --- |
| `强` | 有直接、重复且至少局部因果的证据；合理替代解释明显减少 |
| `中` | 现象较稳定，但因果方向、机制或泛化至少有一项重要限制 |
| `弱` | 主要是相关、自报、单一范式、小样本或间接代理 |
| `冲突` | 有质量相当的证据给出不同结果，需寻找条件而非算简单平均 |
| `未知` | 精度不足、问题未定义或证据无法区分竞争解释 |

如果命题只是“X 与 Y 相关”，横断大样本和多次重复可以构成强相关论据；同一资料对“X 导致 Y”仍可能很弱。强度必须和命题类型一起阅读。

## 4. 正向评估

从理论向证据检查：

1. 这个观念有哪些互不相同的观点？
2. 每个观点能否改写成有对象、条件、比较和结果的分论点？
3. 分论点会做出什么与竞争理论不同的预测？
4. 哪些研究真正检验了这项预测？
5. 研究测的是行为、自报体验、意向、脑活动还是模型参数？
6. 论据支持的是存在、关联、局部因果、机制还是普遍性？
7. 哪些人群、任务、时间尺度和环境构成边界？

## 5. 逆向评估

逆向评估暂时隐藏理论标签，从论据本身开始：

```text
观察到了什么？
  → 真正操纵或测量了什么？
  → 识别了哪个反事实？
  → 最多可以推出什么？
  → 明确不能推出什么？
  → 哪些竞争解释也与结果相容？
  → 是否有研究能区分这些解释？
  → 结果能否上推到分论点、观点和整个观念？
```

### 逆向检查项

1. **去标签**：把“自我效能实验”改写为实际操纵、测量和结果。
2. **看结果单位**：态度、意向、一次选择、长期行为和人生结果不能互换。
3. **看比较**：研究真正比较了什么，而不是标题暗示什么。
4. **看方向**：X→Y、Y→X和共同原因是否被区分。
5. **看纯度**：一个行为指标是否同时混入其他动机；例如信任游戏转账还含利他和平等偏好。
6. **看层级**：群体间相关是否被误用于同一个人的时间变化。
7. **看时间**：短时启动是否被误写成长期内化，撤奖后自由选择是否被误写成任务质量。
8. **看异质性**：平均小效应是否掩盖正、零、负三种场景。
9. **看失败预测**：理论是否能在任何结果后添加新理由保住自己。
10. **看相反命题**：原命题证据不足，不自动证明其反命题。

## 6. 对相反命题的夹逼评估

每组结论同时评估两个极端：

| 极端 A | 证据允许的中间结论 | 极端 B |
| --- | --- | --- |
| 意向完全不影响行为 | 意向有局部因果作用，但远非充分条件 | 有意向就会行动 |
| 奖励总会破坏兴趣 | 特定奖励对特定高兴趣任务可能挤出自由选择 | 奖励总会增强动力 |
| 人从不受多数影响 | 一致多数可引发部分从众，受盟友和文化调节 | 人会盲从多数 |
| 自述全部虚构 | 自述适合报告体验和认可理由，不能单独识别全部机制 | 自述就是实际原因 |
| 复杂系统毫无因果 | 可解释生成机制与概率，具体结果可能不可点识别 | 每次结果都有可恢复的唯一原因 |

这种方法叫“夹逼”，目标不是选一个中庸答案，而是找出当前论据真正允许的最窄命题。

## 7. 上推规则

论据向上支持分论点时遵守：

- `compatible-only` 不得上推成 `supports`；
- 相关证据不得单独上推成因果观点；
- 单一范式不得单独上推成人类普遍动力；
- 一个分论点成立，不代表同一理论的其他分论点同时成立；
- 如果宽观点是多个分论点的合取，整体强度受最弱必要环节限制；
- 如果宽观点只是“至少一条路径”，应报告每条路径的独立强度和适用比例，而不是简单取最低值。

## 8. 最终结论标签

| 标签 | 含义 |
| --- | --- |
| `保留` | 宽观点在合理条件化后有稳定支持 |
| `缩窄保留` | 强版本不成立，但存在证据支持的窄版本 |
| `改写` | 需要改变因果方向、测量含义或解释层级 |
| `竞争未决` | 多个机制与现有资料相容，无法区分 |
| `暂不采用` | 关键预测缺乏支持或可靠重复 |
| `拒绝强版本` | 反例或高质量冲突证据足以否定普遍、充分或唯一性主张 |
