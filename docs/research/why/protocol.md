# 研究协议

## 1. 把问题写成可以研究的形式

使用这个模板：

> 对于【谁】，在【时间与情境】中，为什么选择/开始/继续/停止【行为 A】，而不是【行为 B】？

如果缺少行动主体、情境、时间或对照行动，先标记 `问题未定义`，不进入理论解释。

同一问题要区分：

| 层次 | 含义 | 常见证据 |
| --- | --- | --- |
| 主体理由 | 当事人有意识认可的理由 | 同步报告、访谈、日记 |
| 主观体验 | 当时感受到的欲望、情绪、努力或意义 | 经验采样、生理测量、自报 |
| 行为机制 | 实际改变行动概率的心理过程 | 实验、纵向研究、计算模型 |
| 情境原因 | 能力、机会、摩擦、规则、他人和环境 | 现场实验、自然实验、行为数据 |
| 历史原因 | 学习史、发展路径和习惯形成 | 纵向数据、个体内重复测量 |
| 功能 | 行为可能产生或曾产生什么效果 | 功能分析、进化与系统模型 |
| 正当性 | 这个行动是否合理、真实或道德 | 规范论证；不由心理实验单独决定 |

## 2. 行为分析清单

每个选题都检查以下环节，但不假设它们必然同时存在：

1. 需要或目标：当事人正在调节什么状态？
2. 主观价值：结果有什么吸引力、成本或意义？
3. 成功预期：当事人觉得自己能做到吗？
4. 时间结构：奖励和成本何时发生？
5. 意向：是否形成了明确承诺？
6. 能力与机会：是否真的可以行动？
7. 触发线索：情境是否自动唤起旧行为？
8. 情绪：恐惧、愤怒、好奇、无聊等如何改变选择？
9. 自我与社会：身份、关系、地位、规范和他人反应有什么作用？
10. 反馈与学习：行为结果如何改变下一次选择？

COM-B 可以用来检查能力、机会和动力是否被混淆，但不能替代更具体的动力机制。

## 3. 竞争解释

研究开始前至少写出两个候选机制：

```text
候选机制：
核心论点：
与其他解释不同的预测：
什么结果会削弱它：
适用对象和情境：
已知替代解释：
```

如果一个解释无论出现什么结果都能成立，标记 `不可证伪故事`。

## 4. 检索流程

### 4.1 种子检索

优先顺序：

1. 近期系统综述、元分析或权威手册；
2. 理论原文和奠基实验；
3. 独立重复、预注册多实验室研究；
4. 现场实验、自然实验和纵向研究；
5. 跨文化、特殊人群和边界条件；
6. 调查、访谈、经验采样和定性研究；
7. 计算、神经和生理研究。

常用来源包括 Crossref、OpenAlex、Semantic Scholar、PubMed、APA/PsycNET、OSF、期刊官网和大学机构库。中文研究用于补充本土样本与语境，核心论点尽量回到原论文。

### 4.2 引文追踪

- 向后：检查种子论文引用的理论和原始实验；
- 向前：检查引用种子论文的重复、修正和新元分析；
- 横向：搜索同一构念的不同名称和相邻学科；
- 反向：主动搜索相反预测和零结果。

反方检索词至少包括：

```text
critique
null effect
failed replication
registered report
boundary condition
moderator
publication bias
measurement validity
cross-cultural
retraction
correction
```

### 4.3 暂停条件

连续两轮引文追踪不再出现新的核心机制、关键反证或重要人群边界时，标记 `本轮饱和`。这只表示当前检索可以暂停，不表示资料已经穷尽。

## 5. 证据卡

每项研究至少记录：

```text
citekey:
完整题名:
研究问题:
样本与场景:
设计:
干预/比较:
主要行为结果:
效应量与不确定性:
是否预注册:
是否独立重复:
数据/材料/代码:
支持的具体论点:
冲突或限定:
可能的替代解释:
适用边界:
DOI/稳定链接:
开放全文:
```

## 6. 关系标签

关系连接的是“研究结果”和“具体论点”，不是一篇论文对整个理论的一次性裁决。

| 标签 | 使用条件 |
| --- | --- |
| `supports` | 事前预测成立，并能区分至少一个真实竞争解释 |
| `conflicts` | 设计有识别力和足够精度，结果与预测相反 |
| `qualifies` | 发现调节条件、人群差异或适用边界 |
| `compatible-only` | 与论点相容，但竞争解释同样相容 |
| `null-imprecise` | 未检出效应，但区间太宽，不能构成反证 |
| `replicates` | 独立研究重现关键预测 |
| `fails-to-replicate` | 有足够检验力的重复未重现关键结果 |
| `correlates` | 只建立相关或预测关系 |
| `self-report` | 记录主体认可的理由或体验 |
| `cannot-distinguish` | 现有证据不能区分竞争机制 |
| `level-mismatch` | 群体、平台或国家证据被直接用于个人内部过程 |
| `corrected` / `retracted` | 来源存在正式更正或撤稿 |

“没有显著性”不自动等于 `conflicts`；“能够讲通”也不自动等于 `supports`。

## 7. 多维质量记录

不使用单一证据等级。分别记录：

- 因果识别；
- 样本与精度；
- 测量效度；
- 预注册与研究者自由度；
- 独立重复；
- 生态效度；
- 跨人群和跨文化泛化；
- 异质性；
- 发表偏差；
- 数据、代码和材料透明度。

不同设计回答不同问题：

| 设计 | 可以较好回答 | 不能单独回答 |
| --- | --- | --- |
| 访谈、日记 | 主体理由、意义与体验 | 无意识过程和因果效应 |
| 横断面调查 | 分布、相关和报告理由 | 因果方向与个体内机制 |
| 纵向/经验采样 | 时间顺序和个体内变化 | 未测混杂仍可能存在 |
| 实验室实验 | 特定干预的局部因果效应 | 真实生活中的长期泛化 |
| 现场实验 | 自然情境中的干预效应 | 机制测量通常较弱 |
| 元分析 | 平均效应、异质性和研究生态 | 不能修复共同的测量或发表偏差 |
| 神经研究 | 某些过程与脑系统的关联 | 不能凭激活区域直接读取动机 |
| 计算模型 | 机制的形式化预测与可行性 | 拟合良好不证明机制唯一真实 |

## 8. 诚实停止规则

复杂本身不是停止符。使用更精确的结论：

| 状态 | 含义 | 接下来做什么 |
| --- | --- | --- |
| `问题未定义` | 缺少主体、行动、情境或对照 | 重写问题 |
| `当前未知` | 尚缺资料，但可想象区分性研究 | 列出所需证据 |
| `证据欠定` | 多个机制符合全部现有证据 | 保留竞争解释 |
| `因果不可识别` | 相同观察数据对应不同因果答案 | 报告假设和所需实验 |
| `部分识别` | 只能得到概率边界 | 报区间，不给唯一原因 |
| `仅统计解释` | 只有人群平均倾向或结果分布 | 不归因到某个具体个体 |
| `随机/路径依赖` | 具体结果在平行运行中不稳定 | 解释概率和生成过程 |
| `涌现/层级错置` | 宏观模式没有统一行动主体 | 解释局部规则与反馈 |
| `仅预测` | 能预测行为但未识别动力 | 不冒充因果机制 |
| `事后故事` | 看见结果后构造且没有新预测 | 只作为待检验假说 |
| `层级不匹配` | 群体规律被用于解释个人一次行为 | 降低结论层级 |

除非存在严格的不可能性证明，避免使用过强的“原则上不可解释”。

## 9. 全文与引用保存

- `references.bib` 保存可复用的书目信息和稳定标识符；
- 开放获取全文可保存至 `full-text/`，并在清单中记录来源和许可；
- 付费墙论文不绕过访问控制，只保存书目信息、摘要级笔记和合法开放版本链接；
- 不以二手转载代替 DOI、期刊页或机构库版本；
- 文件名使用 `citekey--short-title.pdf`，不使用不稳定的下载参数。
